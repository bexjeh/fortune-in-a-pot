A [make.fun](https://make.fun/competitions/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty entry: a Python program that writes exactly one fortune for a houseplant — a line about the plant's own future, grounded in its windowsill.

## Run

```sh
python3 main.py
```

Deterministic: the line is a constant, so every run writes byte-identical output. No network, no randomness, no secrets. The line is also written to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `.`).

## The fortune

> Soon a sunbeam will crown your newest leaf, and your keeper will take full credit for it in front of guests.
